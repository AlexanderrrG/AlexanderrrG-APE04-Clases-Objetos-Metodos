## Descripción del Proyecto
Este repositorio contiene el desarrollo de la Guía Práctica APE 04. Consiste en un sistema básico de control de estudiantes y calificaciones desarrollado bajo el paradigma de Programación Orientada a Objetos (POO). El programa permite registrar estudiantes, ingresar sus 3 notas, calcular automáticamente el promedio y determinar su estado (Aprobado/Reprobado).

El sistema está implementado en dos lenguajes de programación:
- **C++**
- **Java**

## Estructura del Repositorio
El proyecto está organizado de la siguiente manera:
- `/Cpp`: Código fuente e instrucciones de ejecución para la versión en C++.
- `/Java`: Código fuente, clases e instrucciones de ejecución para la versión en Java.
- `/capturas`: Evidencias del funcionamiento del código, capturas de las clases/métodos y el historial de commits.

## Requerimientos Cumplidos
- Uso de clases, objetos y métodos (getters, setters, constructores).
- Validación de notas (rango de 0 a 10).
- Cálculo de promedios (Aprobación >= 7.00).
- Resumen final con la cantidad de estudiantes aprobados y reprobados.
