# Sistema de Control de Estudiantes - Versión Java

Esta carpeta contiene la implementación en Java del APE 04. El programa aplica encapsulamiento estricto y separación de archivos.

## Archivos
- `Estudiante.java`: Contiene la clase `Estudiante` con sus atributos privados, constructores y métodos (getters, setters y cálculos).
- `Main.java`: Contiene la clase principal que maneja la entrada de datos (`Scanner`), validaciones y la lista de objetos usando `ArrayList`.

## Instrucciones de Ejecución
Puedes ejecutar este proyecto en tu entorno de desarrollo favorito o desde la línea de comandos.

**Si usas la terminal (JDK instalado):**
1. Abre una terminal en esta carpeta.
2. Compila ambos archivos `.java` con el siguiente comando:
   ```bash
   javac Estudiante.java Main.java
